LIFTLOG - GITHUB PAGES SETUP

1. Extract this folder.
2. On GitHub, create a new repository named liftlog (or another name).
3. Upload all files from this folder to the repository root. The site entry file must be named index.html.
4. Open the repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
6. Wait for the Pages URL shown on the settings screen. Open it on your phone.
7. On iPhone: open the URL in Safari, tap Share, then Add to Home Screen.
   On Android: open it in Chrome, open the menu, then Install app or Add to Home screen.

Important:
- GitHub Pages is public hosting. The tracker has a client-side demo login (Jack / 240299); anyone who can access the site can inspect its code. Do not use it for confidential information.
- Tracker data stays in the browser where it is entered. It does not sync between your computer and phone or between users. Shared data needs a backend.
- The service worker provides an offline app shell after the first online visit, but live shared syncing still needs internet and a backend.
